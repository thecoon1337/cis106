## What is a graphical user interface (GUI)?

- A set of programs that allows a user to interact with the computer system via icons. windows, and various other visual elements.

## What is a desktop environment?

- An implementation of the desktop metaphor made of a bundle of programs running on top of a computer operating system which shares a common GUI.

## What is the command line interface (CLI)?

- An interface that allows the user to interact with the computer by inputting commands.

## How do I access the command line interface (CLI)?

- Can be accessed through a terminal emulator or a Linux console.

## What is a virtual console?

- A terminal session that runs in Linux system memory.

## What is a terminal emulator?

- A program that allows you to access Linux CLI when using the GUI.

## What is bash?

- The default command‑line shell used on most Linux systems.

## What is the Shell Prompt?

- The terminals way of letting you know the shell is ready to accept input.

## Definition, usage, and examples of the following commands: clear echo date free uname history man tldr cheat hostname df du figlet
- clear - clears the terminal screen
- echo - display a line of text
- date - print or set the system date and time
- free - display amount of free and used memory in the system
- uname - Prints system information
- history - view command history
- man - an interface to the system reference manuals
- tldr - shows simplified help pages
- cheat - cheat sheets for commands
- hostname - show or set the system's host name
- df - report file system space usage
- du - estimate file space usage
- figlet - Prints large ASCII-art text
